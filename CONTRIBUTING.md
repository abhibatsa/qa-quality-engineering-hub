# Contributing

Same flow as the rest of this repo family: fork, feature branch, commit,
PR.

## Style guide specific to this repo

- This repo's job is to be the comprehensive QA/QE practitioner
  reference — process AND technical AND AI-QA, at knowledge-base depth.
  It is explicitly NOT a career-prep or interview-prep repo (those are
  sdet-automation-career-prep and ai-test-engineering-career-prep) — if
  new content is really "how do I get hired," it belongs in one of those
  instead, linked from here.
- SRE, SLOs, incident response, and observability dashboards are
  explicitly out of scope — link to the Observability & Monitoring repo
  rather than duplicating.
- Process docs (STLC, estimation, traceability) should include a real
  example, not just definitions — the goal is usable reference material,
  not a glossary.
- Tooling docs (Allure, Kibana, Splunk, etc.) should stay current — this
  category ages faster than process content, revisit periodically.
